# خادم محرر الاختبارات – الإصدار السابع

هذا المجلد يحتوي ملفات الخادم فقط. لا ترفع ملف محرر HTML أو ملفات أخرى إلى هذا المستودع الآن.

## التوافق مع الإصدار السابع
ينفذ المسارات التي يستدعيها الملف:
- `GET /health`
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/exams`
- `PUT /api/v1/exams/<id>`
- `POST /api/v1/exams/<id>/publish`
- `GET /api/v1/exams/<id>/submissions`

ويضيف صفحة الطالب:
- `GET /s/<public-token>`
- `GET /api/v1/student/<token>`
- `POST /api/v1/student/<token>/start`
- `POST /api/v1/student/<token>/submit`

## النشر
1. ارفع محتويات هذا المجلد فقط إلى مستودع GitHub جديد وفارغ.
2. في Render اختر New > Blueprint، ثم اربط مستودع الخادم.
3. راجع الخطة والتكلفة قبل إنشاء قاعدة البيانات. ملف `render.yaml` يطلب قاعدة PostgreSQL بخطة Basic؛ لا تستبدلها بقاعدة SQLite مؤقتة للإنتاج.
4. بعد نجاح النشر انسخ عنوان الخدمة HTTPS، ثم ضعه في خانة عنوان الخادم في محرر الاختبارات واضغط اختبار الاتصال.

## ملاحظات مهمة
- قاعدة PostgreSQL تحفظ الحسابات والاختبارات والإجابات عبر إعادة تشغيل الخدمة.
- حساب كل معلم منفصل؛ لا توجد لوحة مدير أو حساب مدير مركزي.
- كلمة المرور تخزن بصورة hash، ورمز الدخول صالح لمدة 30 يوماً.
- يحدد وقت الاختبار من لحظة ضغط الطالب «بدء الاختبار»، ويُتحقق من انتهاء المدة في الخادم.
- الإصدار السابع يرسل نص السؤال والسطور والدرجة فقط عند النشر؛ لذلك تعرض صفحة الطالب خانة إجابة نصية لكل سؤال. لا توجد في حمولة النشر الحالية بيانات اختيار من متعدد/صح وخطأ أو تصحيح آلي.
- هذا الإصدار الأولي يستقبل الإجابات النصية ويعرضها للمعلم عبر زر «إجابات الطلاب». لم نختبره بعد على حساب Render الفعلي.
- قبل الاستخدام الحقيقي، اختبر حساباً تجريبياً واختباراً تجريبياً وإرسال إجابة، ولا تشارك بيانات طلاب حقيقية أثناء الاختبار الأول.
